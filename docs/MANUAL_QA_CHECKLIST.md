## E. 手机船舶传感器 → NMEA 输出

### QA-P0-016 — RX/TX 独立性与固定心跳

本测试执行两次：第一次选择 **TCP 客户端**，并为 RX 和 TX 使用不同端口；停止后选择 **TCP 服务器**，让一台海图仪或平板连接到页面显示的手机地址。两次都持续观察至少 10 分钟，并包含手机船首向数值完全不变化、Boat HDT/VHW 持续输入的时间段。

- 预期：RX 始终保持连接；TCP 客户端只连接所选 TX 端点；TCP 服务器属于同一个统一 NMEA Output 产品，而不是第二套“共享”开关；Phone HDT 约 5 Hz 且相邻间隔不超过 400 ms；Boat 输入不能替换或抑制 Phone/App Feed，也不能被原样转发；停止输出只关闭 TX 客户端或监听器，不能停止 RX；“实时输出”与“上次已停止会话”明确分开；没有 TCP Server 客户端时“实际写入”为 0。
